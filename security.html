🛡️ POLITIQUE DE SÉCURITÉ

🔐 Authentification

L'API REST utilise JWT (JSON Web Tokens) avec expiration après 8 heures. Support 2FA optionnel (TOTP).

⚠️ Rate Limiting

Limitation à 50 requêtes par heure et 200 par jour pour prévenir les abus.

📜 Logs d'accès

Toutes les actions sont enregistrées dans logs/api.log.

🛡️ Vulnérabilités couvertes (CVE)

CVE-2017-0144 - EternalBlue (SMB) - CRITICAL
CVE-2019-0708 - BlueKeep (RDP) - CRITICAL
CVE-2014-0160 - Heartbleed (OpenSSL) - HIGH
CVE-2020-0796 - SMBGhost - CRITICAL
CVE-2021-41773 - Apache Path Traversal - HIGH

🔒 Bonnes pratiques recommandées

  • Changez le mot de passe par défaut (`admin123`)
  • Utilisez HTTPS en production
  • Activez le 2FA pour les comptes sensibles
  • Limitez les IPs autorisées
