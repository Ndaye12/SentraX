# Feuille de route SENTRAX

## ✅ Version 3.1.0 (actuelle - Mai 2026)

### Réalisé

#### Core
- [x] 10 scanners réseau professionnels
- [x] Interface graphique Tkinter
- [x] API REST complète avec JWT
- [x] Dashboard web avec thème clair/sombre
- [x] Authentification JWT (expiration 8h)
- [x] Double authentification (2FA TOTP)
- [x] Rate limiting anti-bruteforce
- [x] Réinitialisation mot de passe (lien 1h)
- [x] Création de compte utilisateur
- [x] Export PDF des rapports
- [x] Envoi de rapports par email (template)
- [x] Historique SQLite
- [x] Tests unitaires et d'intégration
- [x] CI/CD GitHub Actions
- [x] Documentation complète (7 fichiers)
- [x] EXE autonome (Windows, ~30 MB)
- [x] Support Docker

#### Scanners (10)
- [x] 🤖 AI Predictive Scanner
- [x] 🌐 OSINT Scanner
- [x] 🤝 P2P Scanner
- [x] 👻 Passive Scanner

- [x] 👑 Expert Scanner PRO
- [x] 🔥 Ultra Scanner PRO
- [x] 🔌 SNMP Scanner
- [x] 📡 DNS Scanner

#### Avancées

- [x] Plugin HTTP Enumeration
- [x] Plugin SMB OS Detection
